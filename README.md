# IRLISE RISTORANTE 2.1

**3D Restaurant Simulation Game**

Play the production release: [IRLISE RISTORANTE](https://irlise-ristorante.pages.dev)

Version: `2.1.0`

## Update 2.1 — Daily Missions

- Three daily objectives: deliver six dishes, complete two customer orders, and earn 1,500 coins in sales.
- Each objective grants its coin reward automatically when completed.
- Mission progress is saved with the existing local save data and resets when the in-game day changes.
- Existing Update 2.0 saves are retained; the new mission data is added without resetting restaurant progress.

## Existing systems retained

3D restaurant simulation, customers, kitchen workflow, staff and shifts, levels and XP, market and inventory, settings, language selection, save import/export, and Owner's Office unlock progression.
